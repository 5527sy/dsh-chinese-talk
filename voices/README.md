# voices/ — 音色库

`voices/` 下的**每个子文件夹 = 一个 TTS 音色**，文件夹名即音色名（建议英文/数字，
避免 URL/配置编码问题；中文名也可用，示例默认 `我的声音`）。

## 添加一个音色

在 `voices/` 下新建子文件夹，放入两个文件：

```
voices/
└── 我的声音/
    ├── ref_audio.wav      # 参考音频：3~20 秒干净人声（推荐 10s 左右）
    └── ref_text.txt       # 这段音频【实际朗读的文本】，逐字一致（含标点）
```

- **参考音频质量决定克隆相似度**：单一人声、无背景音乐/杂音/混响；
  用你自己的话自然朗读一段即可（说什么都行）。
- **MP3 也可以**：桥接启动时用 soundfile 读取（libsndfile 支持 mp3）；若读不了，
  先用 ffmpeg 转 wav 再放入。
- 参考文本必须与录音**逐字一致**（标点也对齐）——文本-音频错位会明显拉低相似度。
- 新增/删除音色后**重启桥接**生效（启动时扫描一次）。

## 切换音色

- `bridge-config.json` → `persona.default_voice` 设为默认音色文件夹名；
- 浏览器插件侧边栏「🎚️ 音色」下拉可随时热切换（下一句合成即生效，无需重启）。

## 提示

- 示例音色不随仓库分发（参考音频/文本属个人素材）。
- 不同人的音色建议分开文件夹，方便切换对比。
